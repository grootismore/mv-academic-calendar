## 0.1.2 - 2026-11-06

The packages no longer contain URL-like text in their code and calendar files, so security scanners have nothing to flag. They never made network requests, and still don't. The credit line is shorter and the calendar descriptions say "see the Ministry". No change to the calendar data.

## 0.1.1 - 2026-11-05

Package pages on npm and PyPI improved: clearer descriptions, more search keywords, richer metadata, and a fuller README with examples. No change to the calendar data.

## 0.1.0 - 2026-11-04

First release of the npm and PyPI packages.

- 12 calendars: 2015, 2017 to 2020, the academic years 2021-2022, 2022-2023 and 2023-2024, and 2024 to 2027
- 471 events across terms, exams, mid-term breaks and public holidays
- Offline data, no dependencies, iCalendar text for every calendar
