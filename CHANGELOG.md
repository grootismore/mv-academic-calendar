# Changelog

Notable changes to the calendar data and the packages. Newest first. New entries are written automatically whenever the calendars change.

## 0.1.0 - 2026-11-04

First release of the npm and PyPI packages.

- 12 calendars: 2015, 2017 to 2020, the academic years 2021-2022, 2022-2023 and 2023-2024, and 2024 to 2027
- 471 events across terms, exams, mid-term breaks and public holidays
- Offline data, no dependencies, iCalendar text for every calendar
