# FAQ

**Is this official?**
No. It is compiled from the Ministry of Education's published calendars. Check the [Ministry's site](https://www.moe.gov.mv/en/academic-calendar) for the authoritative version.

**Do I need an API key?**
No. The files are public. Fetch them directly.

**How often is it updated?**
When the Ministry publishes a new or revised calendar. Tentative years can change.

**Why does `2023-2024` have a different name from `2026`?**
Since 2021 the school year runs August to June, so those calendars cover two calendar years.

**An event name looks odd or a date looks wrong.**
The data is read from PDFs, so mistakes happen. [Report it](../issues/new?template=data-correction.yml) with a link to the source.

**Can I use this in my app?**
Yes. See [Using the data in your app](Using-the-Data-in-Your-App). Please keep a note that it is unofficial.

**Why is a year missing?**
Not every year has been published or found. `data/index.json` lists exactly what exists.
