# FAQ

<details>
<summary><b>Is this official?</b></summary>

No. It is compiled from the Ministry of Education's published calendars. Check the [Ministry's site](https://www.moe.gov.mv/en/academic-calendar) for the authoritative version.
</details>

<details>
<summary><b>Do I need an API key?</b></summary>

No. The files are public. Fetch them directly.
</details>

<details>
<summary><b>How often is it updated?</b></summary>

When the Ministry publishes a new or revised calendar. Tentative years can change.
</details>

<details>
<summary><b>Why does <code>2023-2024</code> have a different name from <code>2026</code>?</b></summary>

Since 2021 the school year runs August to June, so those calendars cover two calendar years.
</details>

<details>
<summary><b>An event name looks odd or a date looks wrong.</b></summary>

The data is read from PDFs, so mistakes happen. [Report it](../issues/new?template=data-correction.yml) with a link to the source.
</details>

<details>
<summary><b>What is the licence? Can I use it commercially?</b></summary>

The code is MIT and the compiled data is CC BY 4.0, so you can use and change it with credit. The project stores no Ministry documents, only the dates and names extracted from them, and it does not license the Ministry's own publications. See [Licensing](Licensing), and for commercial use consider asking the Ministry in writing.
</details>

<details>
<summary><b>Can I use this in my app?</b></summary>

Yes. See [Using the data in your app](Using-the-Data-in-Your-App). Please keep a note that it is unofficial.
</details>

<details>
<summary><b>Why is a year missing?</b></summary>

Not every year has been published or found. `data/index.json` lists exactly what exists.
</details>
