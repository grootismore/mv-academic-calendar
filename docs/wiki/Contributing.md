# Contributing and corrections

- **A wrong date, name or category:** open a [data correction](../issues/new?template=data-correction.yml) with the calendar year, the event, what it should say, and a link to the source document.
- **A question or an idea:** start a [discussion](../discussions).
- **Something you built with the data:** share it under *Show and tell* in Discussions.

Calendar files are generated and maintained by the repository owner, so please use issues and discussions rather than pull requests for data changes.
