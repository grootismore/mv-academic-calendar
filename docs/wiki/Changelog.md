# Changelog

Every release of the packages is listed in the repository's [**CHANGELOG.md**](../blob/main/CHANGELOG.md), newest first.
Each entry says which calendars changed, how many events were added or removed, and when a calendar's status changed (for example from tentative to final).

The changelog is written automatically: once a day the data is compared with the last release, and a new entry and version appear only when the calendars have changed.
